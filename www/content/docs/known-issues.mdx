## Laravel Valet

If you're using Laravel Valet 2, there's a bug running JSON:API as reported [here](https://github.com/laravel/valet/issues/771).

### Solution

Upgrade to Laravel Valet 3 or use the patch from [laravel/valet#771](https://github.com/laravel/valet/issues/771).

## The provided secret has expired

When using the site previewer in Drupal, the **View** button can return
`The provided secret has expired.` if you stay on the preview screen
longer than the secret lifetime before clicking it.

### Solution

Preview secrets are short-lived by design. Their lifetime is controlled by
the **Secret expiration time** setting of the preview URL generator at
`/admin/config/services/next`. Refresh the preview screen to request a new
preview URL, or increase the expiration time if your editors regularly
spend more than 30 seconds on the preview screen before navigating.

## A republished page keeps returning 404

Unpublishing a page correctly returns a 404, but publishing it again keeps
serving the cached 404 until the Next.js server restarts.

### Solution

The module sends a revalidation when the entity is saved, and the starter
returns `notFound()` instead of throwing on unpublished content, so the flow
works on supported Next.js versions. Cached 404s, however, were not
invalidated by `revalidatePath` in older Next.js releases — upgrade to
Next.js 13.4 or later (Next 14/15 in the 2.x starters), where stale 404s are
purged like any other page.

## The site previewer iframe is blocked on Vercel

Drupal's preview iframe refuses to embed the site when Vercel
**Deployment Protection** is enabled:

`Refused to display 'https://BRANCHNAME-git-preview-XX.vercel.app/' in a
frame because it set 'X-Frame-Options' to 'deny'.`

### Solution

Vercel forces the `X-Frame-Options: deny` header on protected deployment
URLs and it can not be overridden. Either disable Deployment Protection for
the project (or serve the preview deployments from an unprotected domain),
or open the preview URL in a new tab instead of embedding it in the iframe.
