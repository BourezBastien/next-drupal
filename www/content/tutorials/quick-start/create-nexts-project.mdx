Now that we have enabled the modules, we can create our Next.js project and connect it to Drupal.

We are going to use the [basic starter](https://github.com/chapter-three/next-drupal/tree/master/starters/basic-starter).

---

## Create Project

Run the following command to create a new Next.js project:

```sh
npx create-next-app -e https://github.com/chapter-three/next-drupal-basic-starter
```

---

## Add a Next.js Site in Drupal

To connect a Next.js project, you need to add a Next.js site on the Drupal side:

1. Navigate to `/admin/config/services/next`.
2. Press **Add Next.js site** and follow the instructions. Enter the base URL of your Next.js site (i.e. `http://localhost:3000`) and save.

<Callout>

Tip: Press **Environment variables** for your site at `/admin/config/services/next` to see the environment variables for your Next.js project. You can copy and paste these values in your `.env.local` file.

</Callout>

---

## Connect Drupal

To connect the Next.js project to Drupal, we use [environment variables](https://nextjs.org/docs/basic-features/environment-variables).

1. Copy `.env.example` to `.env.local`.
2. Fill in the following **Environment variables**:

```txt title=.env.local
NEXT_PUBLIC_DRUPAL_BASE_URL=http://example.com
NEXT_IMAGE_DOMAIN=example
```

The starter's `.env.example` also includes variables for authentication and on-demand revalidation:

- `DRUPAL_CLIENT_ID` and `DRUPAL_CLIENT_SECRET`: retrieve or create a consumer at `/admin/config/services/consumer` and copy its **UUID** (client id) and **Secret** (client secret).
- `DRUPAL_REVALIDATE_SECRET`: use the same secret you entered for the **Revalidate secret** of your site in `/admin/config/services/next`.

<Callout icon="⚠️">

**Using DDEV?** The Next.js app must reach Drupal through the DDEV hostname, not `localhost`. Use the site's DDEV URL (i.e. `https://my-drupal-site.ddev.site`) for `NEXT_PUBLIC_DRUPAL_BASE_URL`.

</Callout>

---

## Start Development Server

To start the Next.js development server, run `npm run dev` or `yarn dev`. This starts the development server on `http://localhost:3000`.

Visit [http://localhost:3000](http://localhost:3000) to view the site.
